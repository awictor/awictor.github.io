# Changelog

Initial release.

- Molar mass from a chemical formula with nested parentheses
- Per-element breakdown table
- Standard atomic weights for elements H through Pu
- Guards for unknown elements and unbalanced parentheses
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including groups, counts, and error cases
