# Molar Mass Calculator

Calculate the **molar mass** of any chemical formula — including parentheses and nested groups — from standard atomic weights.

**[Open the tool →](https://awictor.github.io/molar-mass/)**

- Parses formulas like `H2O`, `Ca(OH)2`, `Al2(SO4)3`
- Per-element breakdown with counts and subtotals
- IUPAC standard atomic weights, elements H–Pu
- Dark mode, 100% offline, no dependencies, no tracking

## Example

`C6H12O6` (glucose) → 180.156 g/mol. `Ca(OH)2` → 74.09 g/mol.
