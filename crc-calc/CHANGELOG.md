# Changelog

## 0.1.0
- First release. Multi-polynomial CRC calculator.
- CRC-8, CRC-16 (CCITT-FALSE, XMODEM, ARC, MODBUS), CRC-32 via a parameterized Rocksoft engine.
- Text or hex input; tap-to-copy hex output.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks, all standard check values) + CI.
