# Hat Size Calculator

Convert head circumference to **US fitted hat size**, **EU size**, and the nearest eighth — in centimetres or inches.

**[Open the tool →](https://awictor.github.io/hat-size/)**

- US size = circumference (in) ÷ π, rounded to 1/8
- EU size = circumference in cm
- Centimetre or inch input
- Dark mode, 100% offline, no dependencies, no tracking

## Example

A 57 cm head ≈ EU 57 ≈ US 7 1/8.
