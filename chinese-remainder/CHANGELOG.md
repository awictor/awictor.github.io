# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Chinese Remainder Theorem solver for any number of congruences
- General CRT (non-coprime moduli) with inconsistency detection
- Extended GCD (Bézout) and modular inverse helpers
- Exact BigInt arithmetic internally
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including Sunzi's classic problem
