# Aircraft Fuel Endurance

Calculate an aircraft's endurance and still-air range from usable fuel, burn rate, and true airspeed — with a VFR reserve and the fuel needed for a leg. Free, offline, single-file — nothing leaves your browser.

**Live:** https://awictor.github.io/fuel-endurance/

Part of the [Toolkit](https://awictor.github.io/toolkit/).
