How it works

INI files hold key = value pairs grouped under [section] headers, with ; or # comments. This converts them to a JSON object — top-level keys stay at the root, each section becomes a nested object — and back again. Values are kept as strings (INI has no types), so a round-trip is lossless. Everything runs locally; nothing leaves your browser.
