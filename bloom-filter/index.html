About Bloom filters

A Bloom filter is a compact probabilistic set: it answers "is this item present?" with either definitely no or probably yes — false positives are possible, false negatives never. For n items and a target false-positive rate p, the optimal bit array size is m = −n·ln(p) / (ln2)² and the optimal number of hash functions is k = (m/n)·ln2 = −log₂(p). Notably the size depends only on n and p, not on how big each item is — a 1% filter needs about 9.6 bits per element regardless. Everything runs locally; nothing leaves your browser.
