Grid vs. triangular

In a square grid, plants sit on a simple lattice — divide each bed dimension by the spacing and multiply. A triangular (offset) layout staggers every other row so rows sit only spacing × √3⁄2 apart, fitting roughly 15% more plants in the same bed while keeping the same distance between neighbours. The square-foot gardening count is how many of that plant go in one 12″×12″ square. Spacing is the recommended distance from a seed packet or plant tag.
