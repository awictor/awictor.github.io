# Changelog

## 0.1.0
- First release. Open Graph / Twitter Card / SEO meta tag generator.
- Emits title, description, canonical, og:* and twitter:* tags from a few fields.
- HTML-escaped values; sensible defaults; live title/description length counts.
- Copy button, dark mode, localStorage memory.
- Headless test suite (8 checks incl. exact full-document output) + CI.
