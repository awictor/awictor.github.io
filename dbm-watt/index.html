How it works

The decibel-milliwatt formulas
  • dBm is power referenced to 1 milliwatt: dBm = 10·log₁₀(mW).
  • dBm → mW: mW = 10^(dBm/10); watts = mW ÷ 1000.
  • Watts → dBm: dBm = 10·log₁₀(W × 1000).
  • 0 dBm = 1 mW, 30 dBm = 1 W, 3 dB ≈ double the power, 10 dB = ten times.
  • Gain in a chain simply adds in the dB domain: output = input + gain.
