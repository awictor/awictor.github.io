Contain vs cover

When you fit content into a box, contain scales it to sit entirely inside the box (may leave letterbox bars) using the smaller of the width and height scale factors. Cover scales it to fill the box completely (cropping the overflow) using the larger factor. These are exactly the CSS object-fit: contain and object-fit: cover rules — handy for sizing images, videos, and thumbnails. Everything runs locally; nothing leaves your browser.
