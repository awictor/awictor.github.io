# TV Size & Viewing Distance Calculator

Calculate a TV's **screen width and height** from its diagonal and aspect ratio, plus the **recommended viewing distance**.

**[Open the tool →](https://awictor.github.io/viewing-distance/)**

- Width/height from diagonal via Pythagoras
- Immersive (~1.5× diagonal) and casual (~2.5×) distances
- Aspect presets: 16:9, 21:9, 4:3, 2.39:1
- Dark mode, 100% offline, no dependencies, no tracking

## Example

A 65″ 16:9 TV is ~56.7″ wide, ~31.9″ tall — best viewed from ~8 ft (immersive) to ~13.5 ft (casual).
