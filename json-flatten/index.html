What it's for

Flatten turns nested JSON into a single level of dot.path keys (arrays become list.0, list.1). That's how i18n/translation files, feature-flag configs, and environment maps are often stored — and it makes diffing two configs trivial. Unflatten reverses it, rebuilding the nested structure (numeric segments become arrays). Empty objects and arrays are preserved so a round-trip is lossless. Choose any delimiter. Everything runs locally.
