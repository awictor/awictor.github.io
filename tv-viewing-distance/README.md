# TV Viewing Distance 📺

Find the **ideal TV viewing distance** for your screen size and resolution, or the **biggest TV** that fits your seating distance. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Distance ≈ screen diagonal × a resolution factor (4K ~1.2, 1080p ~1.6).
- Two modes: distance from TV size, or TV size from distance.
- Output in feet and inches.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Pick a mode, enter the value, choose resolution.

> 4K packs pixels tight so you can sit closer; 1080p wants more distance so pixels don't show.
