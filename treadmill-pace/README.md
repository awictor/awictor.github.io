# Treadmill Pace Converter 🏃

Convert treadmill **speed (MPH)** to running **pace per mile and per kilometer**, and back. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- MPH → min/mile, min/km, and km/h.
- Distance covered in 30 minutes.
- Formatted m:ss pace.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter the treadmill speed in MPH.

> A 1% incline roughly matches flat outdoor effort on a treadmill.
