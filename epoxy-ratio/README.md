# Epoxy / Resin Mix Calculator

Calculate **resin and hardener** amounts for a mix ratio (2:1, 1:1, …) and the **volume** needed to cover an area at a pour thickness.

**[Open the tool →](https://awictor.github.io/epoxy-ratio/)**

- Coverage volume = area × thickness
- Split by resin:hardener parts
- Total-from-resin helper
- Dark mode, 100% offline, no dependencies, no tracking

## Example

1000 cm² at 3 mm = 300 mL total. At 2:1 that's 200 mL resin + 100 mL hardener. Measure precisely.
