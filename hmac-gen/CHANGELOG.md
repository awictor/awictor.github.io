# Changelog

## 0.1.0
- First release. HMAC signature generator.
- Pure-JS SHA-256, SHA-1, and HMAC (RFC 2104).
- HMAC-SHA256 / HMAC-SHA1; secret key as text or hex.
- No network calls; one-click copy, dark mode, localStorage memory.
- Headless test suite (10 checks against RFC 4231 / 2202 / FIPS 180) + CI.
