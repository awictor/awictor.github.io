Barbell Plate Loader

Which plates to load on each side

How it works

Greedy plate loading
  • Weight per side = (target − bar) ÷ 2. Plates load symmetrically, so each side carries half the added weight.
  • Starting from the heaviest plate, it takes as many as fit, then moves down: 25, 20, 15, 10, 5, 2.5, 1.25 kg (or the standard lb set).
  • If the target can't be hit exactly with the available plates, the leftover per side is shown so you can round.
  • Everything runs in your browser — nothing is uploaded.
