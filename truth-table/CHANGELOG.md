# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Full truth table from any boolean expression
- Tokenizer + recursive-descent parser (AND, OR, NOT, XOR, parentheses)
- Word and symbol operators; precedence NOT → AND → XOR → OR
- Tautology / contradiction detection, alphabetical variable ordering
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including operator semantics, precedence, and De Morgan's law
