# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- AWG → diameter (mm, inch) and cross-sectional area
- Diameter → AWG (reverse conversion)
- Handles 0/00/000 gauges via 0, −1, −2
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests against the AWG 36 = 0.127 mm definition and AWG 0/10/40 references
