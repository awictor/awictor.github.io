# Changelog

## 0.1.0
- First release. .env ⇄ JSON converter.
- Parse dotenv (comments, blanks, export, single/double quotes, escapes).
- Serialize JSON object back to .env, quoting only when needed.
- Dark mode, per-mode memory, one-click copy.
- Headless test suite (10 checks, incl. round-trips) + CI.
