# Changelog

Initial release.

- Normalized similarity percentage (1 − distance / max length)
- Case-sensitive, Unicode-code-point comparison
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including the kitten→sitting textbook case and similarity edge cases
