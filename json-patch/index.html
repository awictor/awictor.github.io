About JSON Patch (RFC 6902)

A JSON Patch is an array of operations that transform a JSON document — the standard way to send partial updates to an API (PATCH requests). Each op names a target with a JSON Pointer (RFC 6901) path like /numbers/0. The six operations are add, remove, replace, move, copy, and test (which asserts a value and aborts the patch if it doesn't match). Ops apply in order; use /- to append to an array. Everything runs locally; nothing leaves your browser.
