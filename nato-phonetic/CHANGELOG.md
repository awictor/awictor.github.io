# Changelog

## 0.1.0
- First release. NATO phonetic alphabet speller.
- Two-way: text → phonetic (Alfa Bravo Charlie) and phonetic → text.
- Official ICAO/NATO spellings + digit words; decoder accepts aliases (Alpha, Juliet, Niner, Tree, Fife, Fower).
- Reference chart, copy button, dark mode, localStorage memory.
- Headless test suite (10 checks, full A–Z/0–9 round-trip) + CI.
