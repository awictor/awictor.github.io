# Anniversary Gifts 🎁

Look up the **traditional and modern wedding anniversary gift** for any year, plus the next milestone. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Traditional (Victorian) and modern gift for every named year through 15, then each five-year milestone to 60.
- Tells you when a year isn't named and points to the next milestone.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter the anniversary year.

> The list is a tradition, not a rule — gift by the couple's taste when in doubt.
