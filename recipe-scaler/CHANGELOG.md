# Changelog

## 0.1.0
- First release. Recipe ingredient scaler.
- Scale by servings ratio or halve/double/triple; results snap to clean cooking fractions.
- Parses mixed numbers, decimals, and unicode fractions (½, ¾, ⅓…).
- Only leading quantities scaled; steps/headings pass through untouched.
- Copy button, dark mode, localStorage memory.
- Headless test suite (11 checks, fraction round-trips) + CI.
