# Changelog

## 0.1.0
- First release. Glob → regular expression converter.
- Supports *, **, ?, [abc]/[!abc]/ranges, {a,b} alternation, \ escapes; anchored full match; case-insensitive flag; live path testing.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks) + CI.
