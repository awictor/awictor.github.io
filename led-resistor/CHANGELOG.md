# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- LED current-limiting resistor R = (V_supply − V_forward) / I
- Resistor power dissipation and nearest standard E12 value
- LED color presets; supply-vs-forward-voltage guard
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including 5V/2V/20mA → 150 Ω and E12 rounding
