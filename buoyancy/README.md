# Buoyancy Calculator

Calculate **buoyant force**, **displaced volume**, **apparent weight**, and whether an object floats using Archimedes' principle.

**[Open the tool →](https://awictor.github.io/buoyancy/)**

- Buoyant force F = ρ·V·g
- Float/sink verdict from average density
- Apparent (underwater) weight
- Presets for fresh water, seawater, and air
- Dark mode, 100% offline, no dependencies, no tracking

## Example

An 80 kg object of 0.1 m³ has average density 800 kg/m³ — it floats in water and feels ~196 N lighter submerged.
