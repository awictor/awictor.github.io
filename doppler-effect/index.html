About the Doppler effect

When a wave source and observer move relative to each other, the observed frequency shifts — higher (blueshift) when approaching, lower (redshift) when receding. For sound, source and observer velocities enter separately because the medium (air) is the reference frame: f′ = f·(c + v_obs)/(c − v_src). For light there is no medium, so only the relative speed matters via special relativity: f′ = f·√((1+β)/(1−β)) for approach. This is how radar guns, weather radar, medical ultrasound, and astronomers measuring galaxy redshift all work. Everything runs locally; nothing leaves your browser.
