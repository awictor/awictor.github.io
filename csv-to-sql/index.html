How it works

Paste CSV with a header row. It's parsed with a proper RFC-4180 reader — quoted fields may contain commas, doubled quotes ("") and newlines. Each cell is emitted as the right SQL literal: empty → NULL, plain numbers unquoted, true/false → booleans, everything else single-quoted with apostrophes escaped (''). Choose one INSERT per row, or a single multi-row INSERT. Everything runs locally.
