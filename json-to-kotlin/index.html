How it works

Paste a JSON object. Strings become String, whole numbers Int (or Long if too big for Int), decimals Double, booleans Boolean, and null becomes Any?. Nested objects generate their own data class (named after the field), and arrays become List<T> from the first element. Keys that aren't valid Kotlin identifiers are wrapped in backticks. Everything runs locally; nothing leaves your browser.
