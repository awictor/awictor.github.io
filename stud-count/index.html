How it works

  • Studs = ceiling(wall length ÷ spacing) + 1 for the end stud.
  • Plate lumber = wall length × number of plates (a single bottom plate plus a doubled top plate is 3×).
  • This is the straight-run count — add extra studs for corners, T-intersections, and to frame each door or window opening.
  • 16" on-center is standard for load-bearing walls; 24" is common for non-bearing interior walls.
