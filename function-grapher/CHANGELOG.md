# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Plot y = f(x) as crisp auto-scaled SVG (no bitmap)
- Embedded recursive-descent parser for f(x): powers, functions, constants (no eval)
- Discontinuity handling — breaks the line at non-finite / very large values
- Zero-axis lines, example presets, dark mode, fully offline
- 10 self-tests on the sampling and extent layer (point counts, spacing, non-finite handling)
