Gronsfeld Cipher

Vigenère with a numeric key

How it works

The Gronsfeld cipher is a Vigenère cipher whose key is a number instead of a word. Each successive letter is Caesar-shifted by the next digit of the key (0–9), cycling through the digits. Letter C = (P + digit) mod 26; decryption subtracts. Case is preserved and non-letters pass through unchanged (they don't consume a key digit). Because digits only shift 0–9, it's weaker than full Vigenère — good for puzzles, not secrets.
