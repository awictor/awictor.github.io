# Birthstone Lookup 💎

Find the **birthstone** and **birth flower** for any month of the year. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Modern birthstone per month, with the accepted alternate where one exists.
- Traditional birth flower per month.
- Great for jewelry, engraving, and birthday gifts.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Pick the birth month.
