# Changelog

## 0.1.0
- First release. Glassmorphism (frosted glass) CSS generator.
- Tint + opacity, backdrop blur (with -webkit- prefix), corner radius, and border controls.
- Live preview over a colorful backdrop; copy-ready CSS.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks) + CI.
