Nihilist Cipher

Polybius square + numeric key

How it works

Each letter is located on a 5×5 Polybius square (I/J share a cell) and written as its row-then-column number (A=11 … Z=55). The key is turned into the same coordinates and added to the plaintext coordinates, digit-wise as whole numbers, cycling over the key — so ciphertext is a list of numbers. Decoding subtracts the key coordinates. Add a square keyword to scramble the grid.
