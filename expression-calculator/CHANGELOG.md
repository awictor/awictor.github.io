# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Recursive-descent parser (no eval()) with correct precedence and right-associative powers
- Operators +−×÷%, unary minus, parentheses, postfix factorial
- Functions (sin/cos/tan/asin/acos/atan/sqrt/cbrt/ln/log/log2/exp/abs/floor/ceil/round/sign) and constants (pi, e, tau)
- Live evaluation, tap-to-insert chips, dark mode, fully offline
- 10 self-tests covering precedence, associativity, functions, constants, and error handling
