SchemaGen

JSON → JSON Schema generator


      

    

    

    
Types are inferred recursively: whole numbers become integer,
      object keys become properties and are all marked
      required, and array items are merged (mixed scalar types collapse to a
      type list, mixed shapes to anyOf). Runs 100% locally.
