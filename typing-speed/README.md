# Typing Speed Calculator

Calculate typing speed in **words per minute (WPM)**, **net WPM** after errors, **accuracy**, and **characters per minute** from characters typed and time.

**[Open the tool →](https://awictor.github.io/typing-speed/)**

- Gross WPM = (chars ÷ 5) ÷ minutes
- Net WPM subtracts a word per error
- Accuracy and CPM
- Dark mode, 100% offline, no dependencies, no tracking

## Example

250 characters in 1 minute with 3 errors = 50 gross WPM, 47 net WPM, 94% accuracy, 250 CPM.
