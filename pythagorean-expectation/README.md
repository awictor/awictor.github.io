# Pythagorean Expectation

Estimate a team's expected win percentage and season wins from points scored and allowed, using Bill James's Pythagorean formula with sport-tuned exponents for baseball, basketball, football, hockey, and soccer. Free, offline, single-file — nothing leaves your browser.

**Live:** https://awictor.github.io/pythagorean-expectation/

Part of the [Toolkit](https://awictor.github.io/toolkit/).
