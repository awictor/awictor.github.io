Fundamental frequency

How a plucked string sings

A string's fundamental pitch follows Mersenne's law: f = (1 / 2L) · √(T / μ), where L is the vibrating length, T the tension, and μ the mass per unit length. Tighten the string or shorten it and the pitch rises; a heavier (thicker) string lowers it. Rearranged, you can size the tension needed for a target note — T = μ (2Lf)² — which luthiers use to pick string gauges.
