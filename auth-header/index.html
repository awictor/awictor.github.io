AuthHeader

HTTP Authorization header builder

Base64 is encoding, not encryption. Basic credentials are trivially reversible — only ever send them over HTTPS. Nothing here is transmitted; it all runs locally.

Basic auth encodes user:password as base64 per RFC 7617. Decoding splits on the first colon, so passwords may contain colons. 100% local.
