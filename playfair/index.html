Playfair Cipher

Classic 5×5 digraph cipher — encrypt & decrypt

Key square (I/J merged, no J)

The keyword fills the grid first (duplicates dropped), then the remaining letters in order.

How Playfair works

Text is split into letter pairs (digraphs); doubled letters get an X filler and an odd final letter is padded with X. For each pair: same row → take the letter to the right; same column → take the letter below; otherwise the two letters form a rectangle → swap to the corner in the same row (wrapping around the edges). Decryption shifts left / up instead. J is written as I.
