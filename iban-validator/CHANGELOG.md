# Changelog

## 0.1.0
- First release. IBAN validator & formatter.
- ISO 13616 mod-97 checksum + structure validation; country + expected-length lookup (20 countries).
- Groups-of-four formatting; check digits and BBAN breakdown.
- 100% client-side. Dark mode, localStorage memory.
- Headless test suite (9 checks, canonical IBAN vectors) + CI.
