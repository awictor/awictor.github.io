# Turkey Roast Time 🦃

Work out turkey **roasting time**, **fridge thaw days**, and **servings** — all from the bird's weight. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Roasting time at 325 °F: 13 min/lb unstuffed, 15 min/lb stuffed.
- Fridge thaw estimate (~1 day per 4 lb) so you buy the bird in time.
- Servings estimate (~1 lb per guest) and the 165 °F doneness reminder.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter the weight and pick stuffed or unstuffed.

> Time is only a guide — always cook to 165 °F in the thickest part of the thigh, then rest 20–30 min.
