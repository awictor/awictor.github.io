# Changelog

- First release. Cooking measurement converter.

- Cups/tbsp/tsp/fl oz/ml/l and g/kg/oz/lb; density-cancelling same-type conversions.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks) + CI.
