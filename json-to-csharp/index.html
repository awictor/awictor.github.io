How it works

Paste a JSON object. Strings become string, whole numbers int (long if too big), decimals double, booleans bool, and null becomes object. Each key becomes a PascalCase auto-property; a JSON key that differs from the C# name gets a [JsonPropertyName] attribute. Nested objects generate their own class (named after the property) and arrays become List<T>. Everything runs locally; nothing leaves your browser.
