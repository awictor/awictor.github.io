How it works

Paste a single object or an array of objects. The tool scans every row, infers each column's type (integer, real, boolean, ISO timestamp, or text), marks a column nullable if any row omits it or has null, and widens conflicting types (e.g. int + float → real, anything mixed → text). Nested objects and arrays are stored as text (JSON). A column literally named id with integer values becomes the primary key. Everything runs locally; nothing leaves your browser.
