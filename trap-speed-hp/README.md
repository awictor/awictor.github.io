# Trap Speed Horsepower

Estimate engine horsepower from quarter-mile trap speed or elapsed time and vehicle weight, and predict trap speed and ET from horsepower — using the classic Fox/Hale drag-strip formulas. Free, offline, single-file — nothing leaves your browser.

**Live:** https://awictor.github.io/trap-speed-hp/

Part of the [Toolkit](https://awictor.github.io/toolkit/).
