# Changelog

## 0.1.0
- First release. MIME type & file extension lookup.
- Extension → MIME and reverse; ~75 common types across images, docs, web, archives, audio, video, fonts.
- Handles multi-dot filenames, leading dots, and any case; live search.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks) + CI.
