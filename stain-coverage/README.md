# Deck Stain Coverage 🖌️

Estimate **gallons of deck stain or sealer** from deck area, number of coats, and coverage rate. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Gallons = area × coats ÷ coverage, rounded up.
- Coverage presets for transparent, semi-transparent, solid, and rough wood.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter deck area, coats, and coverage rate.

> Include railings and stairs in the area — they add up fast and are easy to forget.
