# Helium Balloon Calculator 🎈

Work out how much **helium** and how many **tanks** you need to fill a batch of balloons, from balloon size and count. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Sphere-model balloon volume in cubic feet and liters.
- Balloons per tank and total tanks needed (rounds up).
- Total helium for the whole batch.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter the balloon count, size (inflated diameter), and tank capacity.

> Real fills run a bit under the sphere estimate — buy a little extra for a big event.
