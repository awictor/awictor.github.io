Bifid Cipher

Delastelle fractionation through a Polybius square

How Bifid works

Invented by Félix Delastelle around 1901, Bifid writes each letter's row and column in a 5×5 Polybius square, lists all the rows then all the columns (that's the "fractionation"), and re-reads that stream in pairs to get the ciphertext. Mixing coordinates from different letters spreads each plaintext letter across the output, which defeats simple frequency analysis. I and J share a cell. A period splits the message into independent blocks (classic Bifid uses a fixed period). Everything runs locally.
