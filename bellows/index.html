    How to read this

    Bellows implements a faithful, simplified DEFLATE — the exact algorithm inside every .zip, .gz, and .png. Stage 1 (LZ77) replaces repeated spans with (distance, length) back-references. Stage 2 (Huffman) builds an optimal prefix code so frequent symbols get short bit-strings. The bellows then expands: the bit-stream is decoded back to your exact input and verified byte-for-byte.

    Keyboard: Space play/pause · ←/→ step · Home/End jump · T theme. Full run state lives in the URL hash — just copy the address bar to share.
