# Pool Volume Calculator

Calculate a swimming pool's **volume in gallons and liters** for rectangular and round pools, using the average depth of a sloped bottom.

**[Open the tool →](https://awictor.github.io/pool-volume/)**

- Rectangular and round pools
- Average depth from shallow + deep end
- US gallons and liters at once
- Dark mode, 100% offline, no dependencies, no tracking

## Example

A 40 × 20 ft pool sloping 3 ft to 8 ft (avg 5.5 ft) holds about 32,900 gallons — the number you need for accurate chlorine and salt dosing.
