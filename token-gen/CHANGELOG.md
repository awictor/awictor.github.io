# Changelog

## 0.1.0
- First release. Secure random token & API-key generator.
- Alphabets: hex, base62, base58, base64url, digits.
- Entropy (bits) + strength label; adjustable length 4–128.
- Cryptographically secure (crypto.getRandomValues); one-click regenerate/copy.
- Dark mode, localStorage memory. Headless test suite (8 checks, injected RNG) + CI.
