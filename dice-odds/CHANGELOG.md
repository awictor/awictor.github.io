# Changelog

## 0.1.0
- First release. Dice roll probability calculator.
- Exact sum distribution for any NdM (up to 20 dice) via convolution.
- Expected value, min/max/mode, and at-least/at-most/exactly odds vs a target.
- Distribution bar chart with matching outcomes highlighted.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks) + CI.
