# Changelog

## 0.1.0
- First release. curl → JavaScript fetch() converter.
- Quote-aware tokenizer with line-continuation support.
- Handles method, headers, data (→ body + POST), user-agent, cookie, referer, and -u Basic auth.
- 100% client-side. Dark mode, theme persistence, copy output.
- Headless test suite (10 checks) + CI.
