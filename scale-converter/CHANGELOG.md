# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Real ↔ model size conversion at any scale ratio
- Find the scale (1:N) from a real size and its model size
- Ratio string parser (`1:24`, `2:1`, plain numbers)
- Preset scale chips, unit-agnostic output
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests on the pure functions
