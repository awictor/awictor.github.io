About scale ratios

A scale 1:N means one unit on the model equals N units in real life. To find a model size, divide the real size by N; to find the real size, multiply the model size by N. The unit doesn't matter as long as both sides use the same one — that's why this tool is unit-agnostic. Common scales: 1:24 & 1:18 (diecast cars), 1:87 (HO trains), 1:160 (N gauge), 1:48 & 1:72 (aircraft), 1:100 & 1:50 (architecture), and map scales like 1:25,000.
