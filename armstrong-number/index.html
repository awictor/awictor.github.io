What is an Armstrong number?

An Armstrong number (or narcissistic number) equals the sum of each of its digits raised to the power of the number of digits. For the 3-digit number 153: 1³ + 5³ + 3³ = 1 + 125 + 27 = 153. Every single-digit number qualifies trivially, and the three-digit Armstrong numbers are 153, 370, 371, and 407. They're a classic programming exercise and a bit of recreational number theory.
