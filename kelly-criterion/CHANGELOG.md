# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Full Kelly optimal stake `f* = (b·p − q)/b`
- Fractional Kelly (half/quarter) for volatility control
- Edge (expected value per $1) and expected log-growth per bet
- Approximate bets-to-double; "no edge" flag for losing bets
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including a growth-optimality check
