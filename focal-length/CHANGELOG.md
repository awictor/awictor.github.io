# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Horizontal, vertical, and diagonal angle of view from focal length and sensor size
- Sensor presets (full frame, APS-C, Micro 4/3, 1″)
- Crop factor and equivalent full-frame focal length
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including FOV = 2·arctan(d/2f) and crop-factor cases
