# Changelog

## 0.1.0
- First release. Neumorphism (soft-UI) CSS generator.
- Flat / concave / convex / pressed shapes; auto-derived matching light + dark shadow pair.
- Distance, blur, and intensity controls with a live preview and copy-ready CSS.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks) + CI.
