About Punycode & IDN

What is this?

Internationalized Domain Names (IDN) let domains use non-ASCII characters. Since DNS is ASCII-only, each label is encoded to xn-- + Punycode (the RFC 3492 bootstring algorithm). This tool converts both ways, label by label. Only labels containing non-ASCII are prefixed; pure-ASCII labels pass through unchanged.

Security note: attackers register look-alike (homograph) domains using confusable Unicode characters. Decoding a suspicious xn-- host reveals its real characters.
