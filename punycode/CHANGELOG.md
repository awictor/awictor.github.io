# Changelog

## 0.1.0
- First release. Punycode / IDN converter (RFC 3492).
- Unicode → ASCII (xn--) and ASCII → Unicode, label by label.
- Homograph/look-alike warning when a decoded domain contains non-ASCII.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks, incl. RFC vectors) + CI.
