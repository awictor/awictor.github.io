# Changelog

## 0.1.0
- First release. Unix file permission (chmod) calculator.
- Two-way conversion: octal ↔ symbolic ↔ live checkbox matrix.
- Special-bit support: setuid, setgid, sticky (s/S/t/T).
- Copy-ready `chmod` command + `ls -l` output + plain-English description.
- Dark mode, localStorage memory.
- Headless test suite (10 checks, exhaustive round-trip) + CI.
