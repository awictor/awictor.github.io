# Changelog

## 0.1.0
- First release. Text reflow / hard-wrap / unwrap tool.
- Greedy word wrap to a column width (presets 72/80/100), paragraph-aware.
- Optional break-long-words; unwrap mode joins paragraphs into single lines.
- Copy button, dark mode, localStorage memory.
- Headless test suite (10 checks incl. wrap↔unwrap round-trip) + CI.
