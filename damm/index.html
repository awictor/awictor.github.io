What is the Damm algorithm?

Published by H. Michael Damm in 2004, it produces a single decimal check digit that detects all single-digit errors and all adjacent transpositions — the same guarantees as Verhoeff, but with a single 10×10 totally anti-symmetric quasigroup table and no permutation or inverse tables. Start an interim digit at 0, then for each input digit look up table[interim][digit]; the final interim value is the check digit. A number is valid when running the whole thing (digits + check digit) ends at 0. Everything runs locally.
