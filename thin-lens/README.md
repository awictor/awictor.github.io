# Thin Lens Equation Calculator

Solve the **thin lens equation** `1/f = 1/dₒ + 1/dᵢ` for image distance, focal length, or object distance — with **magnification** and the image type (real/virtual, upright/inverted, enlarged/reduced).

**[Open the tool →](https://awictor.github.io/thin-lens/)**

- Solve for any of f, dₒ, dᵢ
- Magnification `m = −dᵢ/dₒ` and image classification
- Handles virtual images (negative dᵢ) — magnifying glass
- Dark mode, 100% offline, no dependencies, no tracking

## Example

f = 10 cm, object at 30 cm → image at **15 cm**, magnification −0.5 (real, inverted, reduced).
