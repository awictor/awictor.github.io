How it works

  • Tanks are sized by bedrooms (a proxy for occupancy): a common rule is 1,000 gallons up to 3 bedrooms, then +250 gallons per extra bedroom.
  • Estimated daily wastewater flow is roughly 150 gallons per bedroom.
  • Bigger tanks give solids more time to settle, which protects the drain field.
  • Local health codes set the real minimum — always confirm with your county before you build or replace a system.
