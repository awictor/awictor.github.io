# Septic Tank Size 🚽

Estimate the **recommended septic tank capacity** from the number of bedrooms, with daily wastewater flow. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- 1,000 gal up to 3 bedrooms, +250 gal per extra bedroom.
- Estimated daily flow at ~150 gal per bedroom.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter the number of bedrooms.

> Local health codes set the real minimum — always confirm with your county.
