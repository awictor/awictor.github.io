# Betting Odds Converter

Convert betting odds between **American (moneyline)**, **decimal**, **fractional**, and **implied probability** — enter any one format and the rest update instantly, plus the total payout on your stake.

**[Open the tool →](https://awictor.github.io/betting-odds/)**

- All four formats kept in sync, live
- Implied probability (the break-even win rate) from the price
- Payout calculator for any stake
- Dark mode with persistence
- 100% offline, no dependencies, no tracking

## Example

`+150` American = `2.50` decimal = `3/2` fractional = `40%` implied probability. A $100 stake returns $250.
