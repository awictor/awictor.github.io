# Changelog

## 0.1.0
- First release. CSS clip-path shape generator.
- inset / circle / ellipse / polygon with live preview and copy-ready CSS (+ -webkit- prefix).
- Polygon presets: triangle, trapezoid, rhombus, pentagon, hexagon, chevron, star, message.
- Dark mode, localStorage memory.
- Headless test suite (8 checks) + CI.
