# Cat Age Calculator

Convert your cat's age to **human years** and back, with **life stage**, using the standard feline aging curve.

**[Open the tool →](https://awictor.github.io/cat-age/)**

- Cat → human and human → cat, both directions
- Life stage: Kitten / Junior / Adult / Mature / Senior / Geriatric
- First year ≈ 15, second ≈ 24, then +4 per year
- Dark mode, 100% offline, no dependencies, no tracking

## Example

A 3-year-old cat is about 28 in human years (Junior); a 10-year-old is about 56 (Mature).
