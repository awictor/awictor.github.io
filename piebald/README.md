# Piebald

A two-color connectivity logic puzzle: shade every cell black or white so each color stays in one unbroken group and no 2×2 block ever turns solid.

Piebald is a single-file, zero-dependency implementation of the Yin-Yang puzzle. One HTML file contains the whole thing — a real backtracking **solver** that proves each board has exactly one answer, a **generator** that carves puzzles down to a minimal clue set, and the game UI.

## Why it's cool

Three tiny rules, two colors — and surprisingly deep logic falls out of them. Every puzzle is generated by carving a valid full board down to the fewest clues that a pure-logic solver can still finish, then a counting backtracker confirms the solution is unique. So every board you play is provably solvable by deduction alone, never by guessing. And it's all in one hackable ~330-line HTML file with no build step and no network calls.

## Rules

1. All **black** cells form a single orthogonally-connected group.
2. All **white** cells form a single connected group.
3. No 2×2 area is entirely one color.

## Run it

Open `index.html` in any modern browser — double-click it, or serve the folder:

```
python3 -m http.server
# then open http://localhost:8000
```

No dependencies, no build, no network. A date-seeded Daily puzzle loads automatically. Serving over http/localhost (rather than double-clicking) lets the "Copy result card" button use the native clipboard; over `file://` it falls back to a legacy copy path.

## Controls

- **Tap / click** a cell to cycle empty → black → white → empty.
- **Keyboard:** arrow keys move the focus, **Space** / **Enter** cycle the focused cell.
- **Daily** — the date-seeded puzzle of the day (tracks a localStorage streak).
- **Gentle 6×6 / Tricky 8×8 / Fiendish 10×10** — random puzzles; difficulty scales with grid size and clue count.
- **Check** — marks any placed cells that conflict with the unique solution.
- **Hint** — highlights the next forced move on your current board and explains why.
- **Replay logic** — steps through the full deduction chain from the clues (a teaching walk; it never counts as a win).
- **Undo / Redo** — full move history.
- **Symbols** — colorblind-safe glyph + hatch theme.
- **? How to play** — in-app rules and controls (auto-opens on first visit).

Each puzzle is tagged with its hardest required technique (2×2 Chains / Connectivity Forcing / Split Avoidance) and step count. The seed and grid size are encoded in the URL hash, so any board is shareable and replayable by copying the link.

## Accessibility

Keyboard navigation, `role="grid"`/`gridcell` with live `aria-label`s, an `aria-live` status region, a colorblind-safe symbol theme, `prefers-reduced-motion` support, and pinch-zoom left enabled on mobile.
