# Changelog

## 0.1.0
- First release. CSV → JSON and JSON → CSV conversion, both directions.
- RFC-4180 style parser: quoted fields, escaped quotes, embedded commas/newlines.
- Key-union headers, value quoting on output, parse-error messages, copy.
- Dark mode, localStorage memory.
- Headless test suite (6 checks incl round-trips) + CI.
