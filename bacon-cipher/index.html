How it works

The Baconian cipher

Francis Bacon's 1605 cipher encodes each letter as a group of five symbols drawn from two types (here A and B). This tool uses the modern 26-letter version, so every letter maps to a unique 5-bit pattern (A = aaaaa, B = aaaab … Z = bbaab). Because it only needs a binary distinction, the real trick is steganography: hide the two symbols in a cover text — two typefaces, upper/lowercase, or roman vs italic — so the message hides in plain sight.
