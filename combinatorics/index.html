Combinations vs permutations

Both count ways to pick r items from n. A combination (nCr) ignores order — a poker hand is the same cards in any order — so nCr = n! / (r!·(n−r)!). A permutation (nPr) counts order as distinct — like finishing positions in a race — so nPr = n! / (n−r)!. Permutations are always ≥ combinations by exactly a factor of r!. This tool uses an exact multiplicative method, so big counts like the 2,598,960 possible poker hands come out precise. Everything runs locally; nothing leaves your browser.
