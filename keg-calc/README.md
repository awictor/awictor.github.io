# Keg Calculator

Calculate how many pours a **keg** yields at your glass size, plus **cost per serving**.

**[Open the tool →](https://awictor.github.io/keg-calc/)**

- Total ounces, servings, and cost per pour
- Presets: half barrel, quarter, sixtel, Cornelius
- Any pour size (pints, 12 oz, etc.)
- Dark mode, 100% offline, no dependencies, no tracking

## Example

A half barrel (15.5 gal = 1,984 oz) → 124 pints; at $160 that's ~$1.29 per pint.
