The rules of a comfortable stair

You can't have a fractional step, so the tool rounds the number of risers and back-solves the exact riser height. Common US residential code (IRC): riser ≤ 7¾″, tread ≥ 10″. The classic comfort formula is 2 × riser + tread = 24–25″ (about 63 cm). There's always one fewer tread than riser (the top floor is the last "step"). Check your local code before building.
