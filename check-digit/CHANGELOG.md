# Changelog

## 0.1.0
- First release. Barcode & ISBN check-digit validator/calculator.
- EAN-13, UPC-A, ISBN-13, ISBN-10 (with X); auto-detect by length.
- Validate a full code or compute the missing check digit.
- Dark mode, localStorage memory.
- Headless test suite (9 checks against real barcodes) + CI.
