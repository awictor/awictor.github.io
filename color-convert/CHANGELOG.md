# Changelog

## 0.2.0
- Tints & shades — a 10-step lightness scale generated from the current color, click any swatch to copy its hex.
- Added pure paletteScale() helper.

- First release. HEX / RGB / HSL color converter with three synced inputs.
- Native color picker, live swatch, one-tap copy; shorthand hex supported.
- Dark mode, localStorage memory.
- Headless test suite (5 checks incl round-trips) + CI.
