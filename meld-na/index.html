About MELD-Na

MELD (Model for End-Stage Liver Disease) predicts 3-month mortality in liver disease and drives transplant priority. MELD = 3.78·ln(bilirubin) + 11.2·ln(INR) + 9.57·ln(creatinine) + 6.43; lab values below 1.0 are set to 1.0, creatinine is capped at 4.0 (or set to 4.0 with recent dialysis). When MELD > 11, the sodium correction is applied: MELD-Na = MELD + 1.32·(137 − Na) − 0.033·MELD·(137 − Na), with sodium bounded to 125–137. The final score is bounded 6–40.
