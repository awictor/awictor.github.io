About Catalan numbers

The Catalan numbers 1, 1, 2, 5, 14, 42, 132… count a surprising range of things: the ways to correctly match n pairs of parentheses, the number of binary search trees with n nodes, and the ways to triangulate a polygon. The formula is Cₙ = (2n)! / ((n+1)! · n!) = C(2n, n) / (n+1). This tool computes any term with exact integer arithmetic (up to C₃₀, JavaScript's safe range), lists the sequence, and tests membership. Everything runs locally; nothing leaves your browser.
