How it works

  • A bit's cutting edge travels much faster than the shaft — rim speed = π × diameter × RPM. Big bits reach dangerous edge speeds at full router RPM.
  • So large-diameter bits (panel raisers, big roundovers) must be slowed down. Rough guide: up to 1" run 24k, 1–2" 18k, 2–2.5" 16k, 2.5–3.5" 12k, over 3.5" 10k RPM.
  • Only variable-speed routers can slow down; if yours is single-speed (~24k), don't run bits over ~1.25".
  • Keeping rim speed in a sane band (roughly under ~120 mph) means cleaner cuts, less burning, and a bit that won't come apart.
  • Always follow the bit manufacturer's stamped maximum RPM — it wins over any rule of thumb.
