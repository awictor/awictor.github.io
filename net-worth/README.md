# Net Worth Calculator

Calculate your **net worth** from a list of assets and liabilities, with **debt-to-asset ratio**.

**[Open the tool →](https://awictor.github.io/net-worth/)**

- Total assets, total liabilities, net worth
- Debt-to-asset ratio (leverage indicator)
- Enter any number of line items
- Dark mode, 100% offline, no dependencies, no tracking

## Example

$313k in assets and $198k in liabilities → $115k net worth, 63% debt-to-asset ratio.
