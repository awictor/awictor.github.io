Flow, area, and velocity

Volumetric flow rate is cross-sectional area times average velocity: Q = A · v, with A = π (d/2)². Because area grows with the square of diameter, doubling pipe width quadruples the flow at the same speed. Rearranged, you can find the velocity a given flow needs — useful for keeping speeds in a safe range (roughly 0.6–2.4 m/s for water to avoid noise and erosion). Assumes the pipe runs full.
