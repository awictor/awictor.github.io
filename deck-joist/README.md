# Deck Joist Span 🔨

Look up the **maximum deck joist span** for common lumber sizes and on-center spacing (Southern Pine, 40 psf), and check whether your span passes. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Span table for 2×6 through 2×12 at 12", 16", and 24" on-center.
- Instant pass/fail check against your actual span.
- Formatted feet-and-inches maximum.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Pick joist size and spacing, enter your span.

> A planning estimate — always confirm against your local code and lumber species.
