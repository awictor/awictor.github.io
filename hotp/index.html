HOTP vs TOTP

HOTP (RFC 4226) derives a one-time code from a shared secret and a counter that increments each use — used for event-based tokens and some hardware keys. TOTP (the usual authenticator app code) is HOTP with the counter set to the current time step. This tool implements SHA-1, HMAC-SHA1, and the dynamic-truncation step from scratch, and matches the RFC 4226 reference vectors exactly. Keep secrets private; this all runs locally.
