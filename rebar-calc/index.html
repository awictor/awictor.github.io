Laying out a reinforcing grid

A slab is reinforced with a grid of rebar spaced evenly on center. The number of bars running one way is floor(span ÷ spacing) + 1 — the +1 counts the bar at both edges. Bars running along the length span the full length, and bars running along the width span the full width; total linear footage sums both. Tighter spacing means more steel and more strength. This ignores overlap/lap splices and edge cover, so add ~10% for waste and laps. Everything runs locally; nothing leaves your browser.
