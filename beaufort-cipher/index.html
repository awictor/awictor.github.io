How the Beaufort cipher works

Named after Rear-Admiral Sir Francis Beaufort, this polyalphabetic cipher computes each output letter as key − text (mod 26) — the reverse of Vigenère's addition. Its neat property is that it's self-reciprocal (an involution): running the ciphertext through the exact same process with the same key gives back the plaintext, so there's only one operation to remember (that's why it was used on the WWII Hagelin M-209 machine). The keyword repeats over the message; non-letters are dropped and text is upper-cased. Everything runs locally.
