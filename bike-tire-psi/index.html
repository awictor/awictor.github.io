How it works

  • "System weight" is you plus the bike and any gear — that's the load the tires carry.
  • Pressure rises with weight and falls as tires get wider, so a wide tire runs far softer for the same rider.
  • Run the front ~10% lower than the rear: the rear carries more weight.
  • This is a starting point — drop pressure for comfort and grip, add for speed on smooth roads, and never exceed the tire's max.
