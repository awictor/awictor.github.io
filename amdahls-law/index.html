Amdahl vs. Gustafson

Amdahl's Law answers: for a fixed problem, how much faster does it run on N cores? Speedup = 1 / ((1−p) + p/N), where p is the fraction that can run in parallel. The serial part (1−p) caps the speedup at 1/(1−p) no matter how many cores you add — so 90% parallel can never beat 10×. Gustafson's Law reframes it for a scaled problem (bigger data on bigger machines): speedup = (1−p) + p·N, which grows linearly. Use Amdahl to judge latency on a fixed task, Gustafson to judge throughput as you scale up. Everything runs locally; nothing leaves your browser.
