# Changelog

## 0.1.0
- First release. Credit card brand detector & Luhn validator.
- Detects Visa/Mastercard/Amex/Discover/Diners/JCB/UnionPay by IIN prefix.
- Luhn checksum validation; brand-aware formatting + last-4 masking; IIN display.
- 100% client-side. Dark mode, localStorage memory.
- Headless test suite (9 checks, canonical test PANs) + CI.
