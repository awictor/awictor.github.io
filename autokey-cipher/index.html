Autokey Cipher

A Vigenère that keys itself with the message

How the Autokey cipher works

Blaise de Vigenère's autokey cipher (1586) fixes the big weakness of the ordinary Vigenère: instead of repeating the keyword over and over — which leaks a period an attacker can find — it uses the keyword once, then continues the keystream with the plaintext itself. Each letter is shifted by its keystream letter (A=0…Z=25, mod 26). Decryption is sequential: you recover a plaintext letter, then feed it back to decrypt the next. Non-letters are dropped and everything is upper-cased. Everything runs locally.
