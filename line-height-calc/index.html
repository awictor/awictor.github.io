Ratio, pixels, and leading

A unitless line-height (like 1.5) scales with font size and is the recommended CSS value; multiply by the font size to get the rendered pixel line-height (16px × 1.5 = 24px). Leading is the extra vertical space beyond the glyphs — line-height minus font size — split half above and half below each line (half-leading). For comfortable body text, aim for a ratio of about 1.4–1.6; tighten it for large headings. Everything runs locally; nothing leaves your browser.
