# Rental Yield Calculator

Calculate **gross** and **net rental yield** for a property from rent, expenses, and value.

**[Open the tool →](https://awictor.github.io/rental-yield/)**

- Gross yield = annual rent ÷ property value
- Net yield subtracts running costs first
- Rent needed for a target yield
- Dark mode, 100% offline, no dependencies, no tracking

## Example

$1,500/mo rent on a $300,000 property → 6.0% gross; with $4,000/yr expenses → 4.67% net.
