# Changelog

## 0.1.0
- First release. Code 128 (subset B) barcode generator.
- Encodes printable ASCII with an automatic mod-103 check digit; crisp SVG output.
- Adjustable bar width/height, optional human-readable text, download & copy SVG.
- Dark mode, localStorage memory.
- Headless test suite (9 checks, pattern table + known vectors) + CI.
