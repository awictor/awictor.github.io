# Changelog

## 0.1.0
- First release. HTTP security headers analyzer.
- Audits HSTS, CSP, X-Frame-Options/frame-ancestors, X-Content-Type-Options, Referrer-Policy, Permissions-Policy.
- Weighted 0–100 score with an A–F grade; per-header pass/warn/fail detail.
- 100% client-side. Dark mode, theme persistence, example loader.
- Headless test suite (10 checks) + CI.
