# TipSplit 🌹

**Tip & bill split calculator.** Enter the bill, pick a tip, split between people — see the tip, grand total, and exactly what each person owes, with optional round-up. Runs 100% in the browser, offline.

![version](https://img.shields.io/badge/version-0.1.0-e11d48) ![status](https://img.shields.io/badge/status-live-e11d48) [![CI](https://github.com/awictor/tip-split/actions/workflows/ci.yml/badge.svg)](https://github.com/awictor/tip-split/actions/workflows/ci.yml)

## Features

- Tip amount, **grand total**, and **per-person** share
- Quick tip chips (15 / 18 / 20 / 25%) + custom
- **Round-up** each share to the nearest currency unit (shows the small overage)
- Shareable link, dark mode, local persistence, zero dependencies — one `index.html`

Part of [Toolkit](https://awictor.github.io/toolkit/).
