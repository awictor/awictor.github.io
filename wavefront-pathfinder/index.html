Wavefront — quick reference

The teaching hook. The Heuristic Weight slider morphs A* along the spectrum: at 0 it is Dijkstra (ignores the goal, provably shortest, explores everything); at 1 it is textbook A* (admissible, still optimal); above 1 the heuristic is over-weighted (inadmissible) so it rushes the goal but can return a longer path. The OPTIMAL / NOT OPTIMAL badge compares the returned cost against the true shortest cost and flips the instant admissibility breaks.

Benchmark — tournament across fresh mazes

Runs all four algorithms on identical freshly generated mazes and reports aggregate stats. This quantifies the classic claim: A* explores far fewer nodes than Dijkstra for the same optimal cost.
