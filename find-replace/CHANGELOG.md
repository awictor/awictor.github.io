# Changelog

## 0.1.0
- First release. Bulk find & replace with regex.
- Literal or regex find; $1/$2 backreferences; ignore-case and whole-word.
- Live match count; invalid regex flagged and not applied.
- Literal replacement inserts verbatim; one-click copy, dark mode, localStorage memory.
- Headless test suite (12 checks) + CI.
