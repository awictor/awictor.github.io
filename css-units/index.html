Tap a value to copy. CSS defines absolute units from 96px = 1in: 1in = 72pt = 6pc = 2.54cm = 25.4mm. So 12pt = 16px and 1pc = 16px.

When to use which

Screens use px (CSS reference pixels). Print styling often uses pt (points, 1/72 in) or cm/mm. pc (picas, 12pt) shows up in typography. These are all fixed ratios — unlike rem/em, which depend on font size.
