# Lottery Odds Calculator

Calculate the odds of winning a lottery **jackpot** from the number pool, picks, and an optional bonus ball.

**[Open the tool →](https://awictor.github.io/lottery-odds/)**

- Combinations C(n,k) with an optional bonus-ball multiplier
- Presets: Powerball, Mega Millions, EuroMillions, 6/49
- Odds as "1 in N" and as a probability
- Dark mode, 100% offline, no dependencies, no tracking

## Example

Powerball (5 of 69 + 1 of 26) → 1 in 292,201,338.
