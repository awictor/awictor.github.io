# Changelog

## 0.1.0
- First release. JSON → YAML converter.
- Block-style YAML, two-space indent, nested objects/arrays/arrays-of-objects, empty containers.
- Smart quoting for number/boolean/null-like and YAML-special strings (preserves types).
- Copy button, dark mode, localStorage memory.
- Headless test suite (12 checks) + CI.
