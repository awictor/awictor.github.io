# Changelog

## v0.1.0 — 2026-09-12

Initial release.

- Sound level at distance, distance for a target level, and dB change
- Combine two sources by power addition
- Inverse-square law (6 dB per doubling)
- Input guards for distances
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including doubling, ten-x, and +3 dB combining
