Why gauge is everything

Gauge is how many stitches fit in a set width — patterns quote it as stitches per 4 inches (10 cm), measured on a washed swatch. Divide by 4 for stitches per inch, then a piece's width is just stitches ÷ stitches-per-inch, and the cast-on for a target width is width × stitches-per-inch. Get gauge wrong and everything comes out the wrong size, even with the "right" stitch count — a finer gauge packs more stitches into the same inch. If your swatch doesn't match the pattern, change needle size (bigger needles = fewer stitches per inch) rather than fighting your tension. Row gauge works the same way vertically.
