How it works

Paste a JSON object. Strings become String, whole numbers Int, decimals Float, booleans Boolean. Present (non-null) fields get a non-null marker !; a null value becomes a nullable String. Nested objects generate their own type (named after the field), and arrays become GraphQL lists like [Tag!]!. Everything runs locally; nothing leaves your browser.
