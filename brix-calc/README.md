# Brix Calculator

Convert between **degrees Brix** and **specific gravity**, and estimate **potential alcohol** from a sugar reading.

**[Open the tool →](https://awictor.github.io/brix-calc/)**

- Brix ↔ SG (both directions)
- Potential alcohol ≈ Brix × 0.55
- For home winemakers and brewers (refractometer/hydrometer)
- Dark mode, 100% offline, no dependencies, no tracking

## Example

22 °Bx ≈ 1.092 SG ≈ ~12% potential ABV if fermented dry.
