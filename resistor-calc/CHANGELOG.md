# Changelog

## 0.1.0
- First release. Resistor color-code decoder for 4, 5, and 6-band resistors.
- Decodes digits, multiplier, tolerance, and temperature coefficient from band colors.
- Resistance formatted in Ω/kΩ/MΩ/GΩ with tolerance min/max range; live colored resistor drawing.
- 100% client-side. Dark mode, theme persistence.
- Headless test suite (10 checks, canonical resistor values) + CI.
