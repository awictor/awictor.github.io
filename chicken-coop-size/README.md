# Chicken Coop Size 🐔

Work out coop and run square footage and how many nest boxes your backyard **flock** needs. Single offline HTML file, no dependencies, no data leaves your device.

## Use it

Open `index.html` in any browser, or visit the [live version](https://awictor.github.io/chicken-coop-size/).

Enter the number of hens. You get coop floor space, outdoor run space, and how many nest boxes to build.

## How it works

- Standard-size hens need about 4 sq ft of coop and 10 sq ft of run each — more prevents pecking and disease.
- Provide one nest box per four hens, with at least one box even for a tiny flock.
- Bantams need a bit less, heavy breeds a bit more; free-ranging birds can use a smaller run.
- Add roughly 8–10 inches of roost bar per bird, higher than the nest boxes so they don't sleep in them.
