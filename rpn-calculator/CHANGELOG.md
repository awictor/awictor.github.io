# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Stack-based Reverse Polish Notation evaluator (+ − * / ^ %)
- Step-by-step stack trace of every token
- Errors for operand underflow, leftover values, division by zero, and bad tokens
- Dark mode with persistence, fully offline, no dependencies, no eval()
- 10 self-tests including the classic `5 1 2 + 4 * + 3 -` = 14
