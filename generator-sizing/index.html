Running watts, starting watts, and headroom

Motors (fridges, pumps, AC) draw a brief starting surge far above their running draw. A generator must supply every device's running watts plus the largest single starting surge that happens while everything else runs — you don't add every surge, since they rarely start at once. Formula: total running + max(starting − running). Then add a safety margin (~20%) so you're not running the generator at its limit. Enter each appliance's running and starting watts; if a device has no surge, set them equal. Everything runs locally; nothing leaves your browser.
