What is Gray code?

Reflected binary Gray code is an ordering of binary numbers where consecutive values differ by exactly one bit. That single-bit change is why it's used in rotary encoders, Karnaugh maps, and error-resistant position sensing — a reading caught mid-transition can only be off by one step. Converting is a neat bit trick: to encode, gray = n XOR (n >> 1); to decode, XOR each shifted copy back together. Everything runs locally; nothing leaves your browser.
