How it works

  • Battens = ceil(wall width ÷ target spacing) + 1, so both ends land on a batten.
  • Even spacing = wall width ÷ (battens − 1) — a touch tighter than your target so the layout is symmetric.
  • Vertical batten lumber = number of battens × wall height.
  • Add horizontal top and bottom rails (and mid rails for a grid) separately — this covers the vertical battens.
