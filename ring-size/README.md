# Ring Size Converter

Convert ring sizes between **US size**, inner **circumference (mm)**, **diameter (mm)**, and EU/ISO. Measure a ring you own or find your size.

**[Open the tool →](https://awictor.github.io/ring-size/)**

- circumference (mm) = 36.537 + 2.5535 × US size
- EU/ISO size = circumference in mm
- Circumference ↔ diameter (× / ÷ π)
- Dark mode, 100% offline, no dependencies, no tracking

## Example

US size 7 ≈ 54.4 mm circumference and 17.3 mm diameter.
