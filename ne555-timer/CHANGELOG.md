# Changelog

## v0.1.0 — 2026-09-12

Initial release.

- Astable frequency, duty cycle, and high time from R1/R2/C
- Monostable pulse width
- Auto-scaled time-unit display
- Input guards for resistance and capacitance
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including the 480 Hz reference and duty-cycle bounds
