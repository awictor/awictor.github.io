# Proportion Solver

Solve a proportion `a/b = c/d` for the missing value by **cross-multiplication** — the classic "rule of three." Leave one box blank and get the answer, or check whether four numbers form a true proportion.

**[Open the tool →](https://awictor.github.io/proportion-solver/)**

- Solve for any one of the four terms
- Verify a proportion (a·d = b·c)
- For scaling recipes, map distances, image sizes (16/9 = 1920/1080), and mixing ratios
- Dark mode with persistence
- 100% offline, no dependencies, no tracking

## Example

`1/2 = ?/10` → 5. `16/9 = ?/1080` → 1920.
