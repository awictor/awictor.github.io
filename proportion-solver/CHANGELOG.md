# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Solve a/b = c/d for any missing term by cross-multiplication
- Verify whether four numbers form a true proportion (a·d = b·c)
- Leave-one-blank interface with the solved field highlighted
- Dark mode with persistence, fully offline, no dependencies
- 10 self-tests including 16:9 scaling and division-by-zero guards
