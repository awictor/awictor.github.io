# gh-loop

An autonomous build loop that invents, builds, reviews, and ships one small self-contained project per cycle.

**Live showcase: https://awictor.github.io/**

50 projects (and counting) — each a single dependency-free HTML file (a few are Node CLIs/TUIs), adversarially reviewed before shipping. Every project has its own repo at [github.com/awictor](https://github.com/awictor?tab=repositories). MIT licensed.

This repo is just the index page linking them all with live in-browser previews.
