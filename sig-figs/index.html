The rules

Significant figures show a measurement's precision. The rules:

  • All non-zero digits are significant — 1234 has 4.
  • Zeros between non-zero digits count — 100.45 has 5.
  • Leading zeros never count — 0.00456 has 3.
  • Trailing zeros count only with a decimal point — 1000 has 1, but 1000. and 120.0 have 4.
