# Changelog

## 0.1.0
- First release. Color blindness (CVD) palette simulator.
- Protanopia / deuteranopia / tritanopia / grayscale simulation via standard transform matrices.
- Whole-palette grid view; accepts #rrggbb, #rgb, mixed separators.
- Dark mode, localStorage memory.
- Headless test suite (10 checks, known matrix results) + CI.
