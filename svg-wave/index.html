SVG Wave Generator

Smooth wave dividers for website sections

How it works

Each layer is a sine wave sampled across the width and filled down to the bottom edge — the classic "section divider" you drop between two colored blocks. Stack a few layers at slightly different amplitude, wavelength and opacity for depth. Everything is a plain inline SVG: paste it straight into your HTML, or set it as a CSS background with a data URI. Phase is in radians ×100 on the slider.
