# Changelog

## 0.1.0
- First release. CSS selector specificity calculator.
- Scores selectors as (IDs, classes/attrs/pseudo-classes, elements/pseudo-elements).
- Color-coded token breakdown + two-selector comparison with a winner verdict.
- Correct handling of :is()/:not()/:has() (most specific arg), :where() (zero), and pseudo-elements.
- Dark mode, localStorage memory.
- Headless test suite (10 checks, W3C canonical examples) + CI.
