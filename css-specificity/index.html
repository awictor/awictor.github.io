Specificity

CSS selector specificity calculator

Specificity is scored as three numbers: IDs, then classes / attributes / pseudo-classes, then elements / pseudo-elements. Compare left-to-right — a higher ID count always wins. :is(), :not() and :has() take their most specific argument; :where() counts as zero.
