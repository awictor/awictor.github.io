# Changelog

## v0.1.0 — 2026-09-11

Initial release.

- Solve Ax = b (2×2 to 5×5) by Gauss–Jordan elimination with partial pivoting
- Determinant helper and singular-system detection
- Editable coefficient/constant grid with live solving
- Dark mode with persistence, fully offline, no dependencies, no eval()
- 10 self-tests including a classic 3×3, residual check, pivoting, and singular cases
