# Extension Cord Gauge 🔌

Find the right **extension cord gauge (AWG)** from the load in amps or watts and the cord length. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Chart-based sizing for 120 V household cords by load and length.
- Watts → amps conversion built in.
- Warns when a load or run is beyond extension-cord territory.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter the load (amps or watts) and cord length.

> Never chain cords, and unroll a cord fully under load — coiled cords trap heat.
