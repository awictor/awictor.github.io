Angular Size Calculator

How big an object appears from a distance

Size and distance must be in the same units.

How it works

The angular size formula
  • An object of size s at distance d spans an angle θ = 2·arctan(s ÷ 2d).
  • For far-away objects this simplifies to θ ≈ s ÷ d radians — the small-angle approximation.
  • Astronomers measure tiny angles in arcminutes (1/60°) and arcseconds (1/3600°): the full Moon is about 0.5° (31 arcmin) across.
  • Solve any of the three: angle from size and distance, or the size or distance that gives a target angle. Everything runs in your browser.
