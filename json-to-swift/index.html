How it works

Paste a JSON object. Strings become String, whole numbers Int, decimals Double, booleans Bool, and null becomes an optional String? (type can't be inferred from null). Each key is a let constant; nested objects generate their own struct (named after the key) and arrays become [Element]. Every struct conforms to Codable. Keys that aren't valid Swift identifiers are wrapped in backticks. Everything runs locally.
