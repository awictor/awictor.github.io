What it does

Recases every key in a JSON object — recursively through nested objects and arrays — while leaving values untouched. Handy for bridging a snake_case API to camelCase JavaScript (or the reverse for a Python/Ruby backend). Keys are split into words on underscores, hyphens, spaces and camel-case humps, then re-joined in your chosen style. Everything runs locally; nothing leaves your browser.
