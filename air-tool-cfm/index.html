How it works

  • Add up the CFM of every tool you'll run at the same time — CFM, not PSI, is what sizes a compressor.
  • Multiply by a safety factor (about 1.5×) so the pump keeps up and doesn't run continuously.
  • CFM ratings are quoted at 90 psi — compare tools and compressors at the same pressure.
  • A bigger tank buys short bursts of extra air, but sustained use still needs enough pump CFM.
