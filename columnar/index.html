How it works

Columnar transposition

The message is written into a grid row by row under the keyword. The columns are then read out top-to-bottom in the alphabetical order of the keyword's letters (ties broken left-to-right). Only letters are kept; the grid is padded with X so every column is full. Decryption fills the columns back in the same order. The keyword only determines column order — it isn't mixed into the letters.
