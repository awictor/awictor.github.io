About CORS

CORS (Cross-Origin Resource Sharing) headers tell a browser which other origins may read a response. Access-Control-Allow-Origin names the allowed origin (or * for any); Allow-Methods and Allow-Headers list what a preflight request may use; Max-Age caches the preflight. One key rule: if you set Allow-Credentials: true you cannot use * for the origin — you must echo back the specific requesting origin. This tool flags that conflict. Everything is generated locally; nothing leaves your browser.
