Datestone

Hide a year inside a sentence — the lost art of the chronogram, as a live toy.

A chronogram is a phrase whose raised letters, read as Roman numerals M D C L X V I, add up to a year. Datestone uses the historical additive rule: every numeral letter counts at its own value — so IV = 6, not 4. Click any glowing letter to raise it.
