How it works

  • Rule of thumb: guests drink about 2 in the first hour, then 1 per hour after — so total ≈ guests × (hours + 1).
  • Wine: 5 glasses per 750 ml bottle. Liquor: 16 shots per 750 ml bottle. Beer: one drink = one can/bottle.
  • Set the beer / wine / liquor split to match your crowd — the three should add up to 100%.
  • Round up and buy a little extra: leftovers keep, running out doesn't. Have water and a non-alcoholic option too.
