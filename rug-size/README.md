# Rug Size Calculator 🟫

Find the right area rug size for a room: recommended rug dimensions from the room size and the floor border you want, plus the nearest standard rug size.

**[Open the app →](https://awictor.github.io/rug-size/)**

- 100% offline — a single HTML file, no dependencies, no tracking
- Dark mode, keyboard-friendly, works on mobile
- Pure functions with a self-test suite

## How it works

```
rug side = room − 2 × border
```

Leave an even **12–24″** strip of bare floor framing the rug. In a living room, get at least the **front legs** of the sofa on it; in a dining room, extend ~24″ past the table so chairs stay on when pulled out. Round to a standard size (5×8, 8×10, 9×12…). Bigger rugs make a room feel larger.
