# Shoe Size Converter 👟

Convert shoe sizes between **US, UK, EU, and foot length in cm**, for men and women. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- US → UK, EU, and foot length (cm) for men's and women's sizing.
- Based on last-length steps and the EU Paris-point system.
- Honest about approximation — reminds you to check the brand's chart.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter a US size and pick men's or women's.

> Foot length in cm is the most reliable measure. Brands and lasts vary, so treat conversions as a starting point.
