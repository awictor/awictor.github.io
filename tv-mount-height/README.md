# TV Mount Height 🖼️

Find the right **TV mounting height**: screen center at seated eye level and the bracket bottom-edge height, from TV size and your seated eye height. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Screen center at seated eye level (~42" default) for comfortable viewing.
- Bottom-edge mount height and screen height for the diagonal.
- 16:9, 21:9, and 4:3 aspect ratios.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter TV size, aspect ratio, and seated eye height.

> Mounting higher (over a fireplace) works only with a tilting mount.
