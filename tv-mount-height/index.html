How it works

  • Comfort rule: the screen center sits at seated eye level — about 42" from the floor for an average sofa.
  • Bottom-edge height = center − screen height ÷ 2, which is where the bracket ledge usually references.
  • Screen height for a diagonal = diagonal × (aspect height ÷ √(aspect width² + height²)).
  • Mounting higher (over a fireplace) works only with a tilting mount — otherwise you're craning your neck.
