# Changelog

## 0.1.0
- First release. xxd-style hex dump viewer.
- Offset / hex bytes / ASCII gutter; 8 or 16 bytes per line with group gap.
- UTF-8 byte encoding; non-printable shown as dot; byte & char counts.
- Copy button, dark mode, localStorage memory.
- Headless test suite (9 checks, exact output) + CI.
