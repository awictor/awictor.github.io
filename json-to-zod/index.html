How it works

Paste any JSON value. Strings become z.string(), whole numbers z.number().int(), decimals z.number(), booleans z.boolean(), and null becomes z.null(). Objects turn into z.object({…}) with each key, arrays into z.array(…) based on the first element. You also get a matching TypeScript type via z.infer. Keys that aren't valid identifiers are quoted automatically. Everything runs locally; nothing leaves your browser.
