# Changelog

## 0.1.0
- First release. Converts text to 9 cases: camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, dot.case, Title Case, Sentence case, and URL slug.
- Smart tokenizer handling camelCase humps, acronyms, and mixed separators.
- Click-to-copy, dark mode, localStorage memory.
- Headless test suite (5 checks) + CI.
