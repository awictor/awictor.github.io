# Garden Plant Spacing 🌱

Work out how many plants fit a garden bed from its size and the spacing between plants, plus plants per square foot. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Grid layout: plants down length × plants across width.
- Plants per square foot = (12 ÷ spacing)².
- Notes the ~15% bonus from offset (triangular) planting.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser. Enter bed dimensions and plant spacing (inches).
