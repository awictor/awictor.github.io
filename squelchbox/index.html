SQUELCHBOX

TB-303-style acid bassline synth · one HTML file
Click a cell to place a note (click again toggles it off). Red row = accent (louder + brighter, resonant snap), blue row = slide (portamento glide into the note). Keys: Space play/stop · ◀ ▶ select step · ▲ ▼ move its pitch. The whole patch lives in the URL — Copy Link and paste to share.
