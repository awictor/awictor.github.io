# Changelog

## 0.1.0
- First release. Bitwise operations calculator.
- AND/OR/XOR/NOT and <<, >>, >>> on 32-bit integers with two's-complement handling.
- Decimal / 0x hex / 0b binary input; signed, unsigned, hex, octal, grouped binary output.
- Click-to-copy, dark mode, localStorage memory.
- Headless test suite (10 checks) + CI.
