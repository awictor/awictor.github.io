About timecode

SMPTE timecode labels each frame as HH:MM:SS:FF — hours, minutes, seconds, and the frame within that second. The frame count must be below the frame rate (at 24 fps the frames run 00–23). This tool uses non-drop-frame counting: frames map linearly to time as seconds = frames ÷ fps. Real seconds can differ slightly from the clock reading for fractional rates like 23.976, which is exactly why editors track frames, not wall-clock time.
