# Typing Speed Test ⌨️

Measure your typing speed in **words per minute** and **accuracy** with a quick, private, offline test. Single offline HTML file, no dependencies, no data leaves your device.

## Features

- Live net WPM (gross speed minus error rate), accuracy, and elapsed time.
- Character-by-character highlighting of correct and wrong keystrokes.
- Rotating sample sentences; timer starts on your first keystroke.
- Dark mode, mobile friendly, works fully offline.

## Usage

Open `index.html` in any browser and start typing the sentence shown.

> A "word" is standardized as 5 characters. Net WPM rewards accuracy, not just raw pace.
